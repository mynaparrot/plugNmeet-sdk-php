getDurationFromEvents()

AnalyticsFormatter.php : 691

Calculate device duration from start/end and user-leave events.

private getDurationFromEvents(array<string|int, mixed> $events[, string $startStatus = "ANALYTICS_STATUS_STARTED" ][, string $endStatus = "ANALYTICS_STATUS_ENDED" ][, array<string|int, mixed> $leaveEvents = [] ]) : int

Builds a timeline from start, end, and user leave events. A pending device session is closed by the earliest of: matching end event, user leave, or room end.

Uses stripos for prefix matching so values like "ANALYTICS_STATUS_STARTED:node_01" are correctly recognised.

Parameters
$events : array<string|int, mixed>

Device status events (mic_status, webcam_status, etc.)

$startStatus : string = "ANALYTICS_STATUS_STARTED"

Value prefix for start events

$endStatus : string = "ANALYTICS_STATUS_ENDED"

Value prefix for end events

$leaveEvents : array<string|int, mixed> = []

User leave timestamps (ms)

Return values
int —

Duration in seconds
